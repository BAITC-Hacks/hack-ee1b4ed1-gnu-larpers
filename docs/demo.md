# Демо «Граф денег»: 5 минут

## Подготовка

Из корня репозитория установите окружение командой `make setup`, затем выполните `npm run check` и `npm run build`. После этого запустите `make start` и откройте http://127.0.0.1:5173. Для живого пересчёта оставьте второй терминал в корне репозитория. Подготовьте README с разделом «Схема решения» и каталог `out/`.

Для основного демо ключ LLM не требуется. Если дополнительно показываете агента, заранее проверьте доступность провайдера через `make start-agent`; не запускайте одновременно обычный сервер на том же порту. Не показывайте содержимое `.env`.

## Проверка артефактов перед передачей

После `make analyze` запустите из корня:

```bash
uv run --project backend --locked python - <<'PY'
import csv
from pathlib import Path

schemas = {
    "nodes_roles.csv": ["gid", "role", "role_score", "cluster_id", "priority_score", "evidence"],
    "clusters.csv": ["cluster_id", "n_nodes", "n_seed", "sum_kzt_internal", "top_gids", "hypothesis"],
    "top_nodes.csv": ["rank", "gid", "role", "priority_score", "why"],
}
roles = {"consolidator", "transit", "distributor", "terminal", "coordinator", "peripheral"}
tables = {}
for name, schema in schemas.items():
    with (Path("out") / name).open(newline="", encoding="utf-8") as file:
        reader = csv.DictReader(file)
        assert reader.fieldnames == schema, name
        tables[name] = list(reader)
    assert all(all(row[column] for column in schema) for row in tables[name]), name
    print(f"{name}: {len(tables[name])} строк, схема совпадает")
nodes = tables["nodes_roles.csv"]
assert len(nodes) == len({row["gid"] for row in nodes}) == 2248
assert all(row["role"] in roles and 1 <= len(row["evidence"]) <= 200 for row in nodes)
assert all(0 <= float(row[key]) <= 1 for row in nodes for key in ("role_score", "priority_score"))
clusters = tables["clusters.csv"]
assert {row["cluster_id"] for row in nodes} == {row["cluster_id"] for row in clusters}
assert sum(int(row["n_nodes"]) for row in clusters) == len(nodes)
top = tables["top_nodes.csv"]
assert len(top) >= 20
assert [int(row["rank"]) for row in top] == list(range(1, len(top) + 1))
assert [float(row["priority_score"]) for row in top] == sorted(
    (float(row["priority_score"]) for row in top), reverse=True
)
print("Обязательные выгрузки проверены")
PY
```

Количество 2 248 проверяется именно для конкурсного датасета. Для другой выборки сравнивайте число строк с её `nodes.parquet`.
